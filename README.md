# 🛒 E-Commerce Sales Analysis using Excel

## 📌 Project Overview

This project is an E-Commerce Sales Analysis Dashboard created using
Microsoft Excel.

The project transforms raw e-commerce sales data into meaningful
business insights using data cleaning, Pivot Tables, KPI metrics,
charts, and dashboard visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify the most sold product categories
- Find the highest-performing regions
- Analyze sales and profit
- Understand order and shipping patterns
- Build an interactive Excel dashboard

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
- Data Cleaning
- Data Visualization

## 📊 Key KPIs

- 💰 Total Sales
- 📈 Total Profit
- 📦 Total Orders
- 🛍️ Sales by Category
- 🌍 Sales by Region
- 🚚 Sales by Ship Mode

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Category-wise Sales
- Region-wise Sales
- Most Sold Category
- Highest Sales Region
- Ship Mode Performance
- Sales and Profit Performance

## 🔍 Key Features

- Data cleaning and preparation
- Pivot Table-based analysis
- Interactive filters
- KPI cards
- Multiple visualizations
- Business-focused dashboard

## 📂 Project Files

- `E-commerce_Sales_Analysis.xlsx` – Complete Excel analysis and dashboard
- `E-commerce_Dataset.csv` – Raw dataset
- `Dashboard_Screenshot.png` – Dashboard preview

## 💡 Conclusion

This project demonstrates how Microsoft Excel can be used to perform
data analysis and create an interactive business dashboard from
raw e-commerce data.
